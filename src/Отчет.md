# Отчёт по лабораторной работе №3-4
## Нейронная сеть для задачи классификации

**Язык реализации:** Rust  

## Постановка задачи

Цель лабораторной работы: реализовать многослойную нейронную сеть, решающую задачу бинарной классификации. Для обучения сети использовать алгоритмы оптимизации, реализованные в рамках предыдущих лабораторных работ, и сравнить их влияние на качество модели.

Итоговое качество оценивается по формуле:

```
Score = 0.3 × F1(d1) + 0.3 × F1(d2) + 0.4 × F1(d3)
```

## Описание данных

| Датасет | Признаков | Классов | Объём | Разбивка |
|---------|-----------|---------|-------|----------|
| d1 | 2 | 2 | 600 строк | 80% train / 20% test |
| d2 | 4 | 2 | 600 строк | 80% train / 20% test |
| d3 | — | — | закрытый | — |

Оба датасета представляют задачу бинарной классификации. Целевая переменная кодируется в формате one-hot encoding перед передачей в сеть.

**Предобработка данных** (`data_loader.rs`):

1. Загрузка CSV-файла с заголовком.
2. Перемешивание строк в случайном порядке (`rand::seq::SliceRandom`).
3. Z-нормализация каждого признака по столбцу: `x' = (x − μ) / σ`.
4. Разбивка на обучающую и тестовую выборки в соотношении **80 / 20**.
5. One-hot кодирование целевого класса.

## Архитектура нейронной сети

Реализация расположена в файле `model.rs`

### Структура

Сеть содержит один скрытый слой и реализована как последовательность объектов `Layer`, каждый из которых хранит матрицу весов и вектор смещений:

```
Вход (n_features) → Скрытый слой (ReLU) → Выход (Softmax)
```

| Датасет | Вход | Скрытый слой 1 | Скрытый слой 2 | Выход |
|---------|------|----------------|----------------|------|
| d1      | 2 | 16             | 8              | 2    |
| d2      | 4 | 16             | 8              | 2    |

### Инициализация весов

Применяется инициализация **Xavier (Glorot)**:

```
W ~ U(−limit, +limit),   limit = sqrt(6 / (fan_in + fan_out))
```

Это позволяет избежать затухания и взрыва градиентов на старте обучения.

### Функции активации

- **Скрытый слой:** ReLU `f(x) = max(0, x)`
- **Выходной слой:** Softmax нормализует выходы в вероятности классов

### Функция потерь

Кросс-энтропия (categorical cross-entropy):

```
L = −(1/N) × Σ Σ y_true × ln(y_pred + ε),   ε = 1e-15
```

### Прямой проход

Для каждого слоя вычисляется:
```
Z = X · W + b
A = activation(Z)
```

### Параметризация

Веса и смещения всех слоёв записываются в вектор `Vec<f64>` (`get_params`) и восстановить из него (`set_params`). Это позволяет передавать параметры сети в алгоритмы оптимизации без изменений их интерфейса.

## Алгоритмы оптимизации

Обучение нейронной сети сводится к задаче минимизации функции потерь по параметрам:

```
θ* = argmin L(θ)
```

Оба оптимизатора принимают функцию `f: &[f64] → f64` как чёрный ящик. Производные вычисляются численно (`gradient.rs`):

```
∂f/∂xᵢ ≈ (f(x + hᵢ) − f(x − hᵢ)) / (2h),   h = 1e-5
```

### Adam

`optimizers/adam.rs`  
**Гиперпараметры:**

## Метрика

`metrics.rs`

Используется **макро-усреднённая F1-мера**:

```
Precision_c = TP_c / (TP_c + FP_c)
Recall_c    = TP_c / (TP_c + FN_c)
F1_c        = 2 × Precision_c × Recall_c / (Precision_c + Recall_c)
 
Macro-F1 = (1/K) × Σ F1_c
```

где `K` - число классов.
